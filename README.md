# 🎂 Devina's Birthday

A magical birthday adventure celebrating Devina turning 11.

[🎁 Open Devina's Birthday Website](https://techbaseml.github.io/devinas-birthday/)

Cake wishes, five gifts, three mini-games, music, downloadable birthday card and fireworks. Free, with no login or backend.

Edit `config.js` to customize the name, age, wishes or photos. Serve locally with `python3 -m http.server 8000`. GitHub Pages serves the root of `main`.
